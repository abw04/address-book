# Address-Book
Address book website built with modularized javascript. Features include adding contacts, editing, deleting and search. Data is stored using browser local storage.

# Link
Link is at [https://abw-addressbook.netlify.app/](https://abw-addressbook.netlify.app/)

# Features
1. Add contact - adding new contact with complete information validation
2. Edit Contact - updating existing contact with new data
3. Delete contact - deleting existing contact
4. Search Contact - search between existing contact name
